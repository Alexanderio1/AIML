# Лабораторная № 1: линейная регрессия и PCA

Отчёт по заданию на **Appliances Energy Prediction**:

- **[lab1.ipynb](lab1.ipynb)** — выполненный notebook с пояснениями после каждой кодовой ячейки.
- **[report.html](report.html)** — версия для браузера; рисунки встроены, MathJax для формул может потребовать Интернет.
- **[lab1.py](lab1.py)** — полный листинг расчётов, также включённый в приложение отчёта.
- `data/` — исходный CSV и сведения о происхождении с SHA-256.
- `results/` — 6 рисунков, таблицы метрик/VIF и тестовые прогнозы.

В работе есть семь разделов задания: введение, описание данных,
подготовка, ход работы, заключение, источники и приложение.
Исследованы корреляции и VIF, OLS/Lasso/Ridge до и после стандартизированного
PCA, RMSE/R²/MAPE и остатки. Используются 25 числовых признаков, разбиение
80/20 и вложенная CV 5×3. Дополнительные временные эксперименты и календарные
признаки в эту версию не входят.

## Запуск из корня проекта, Python 3.12

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m ipykernel install --prefix "$VIRTUAL_ENV" --name aiml --display-name "Python (AIML)"
python scripts/fetch_data.py
python scripts/run_notebook.py
python scripts/validate_artifacts.py
```

CSV уже включён: токен Kaggle не нужен. Он получен из репозитория автора
исходного исследования; точный источник указан в `data/source.json` и отчёте.
`fetch_data.py` проверяет контрольную сумму и скачивает файл, только если его нет.
`run_notebook.py` выполняет notebook и обновляет HTML, листинг и результаты.
Для расчётов без экспорта отчёта: `python lab1.py`.
После изменения параметров или методики пересмотрите текстовые выводы notebook.

Оценка относится к одному дому и случайному разбиению временных измерений.
Снижение VIF после PCA не гарантирует улучшения метрик; это показано в отчёте.
Исходное исследование: Candanedo et al., *Energy and Buildings*, 140 (2017),
81–97. DOI: https://doi.org/10.1016/j.enbuild.2017.01.083.
